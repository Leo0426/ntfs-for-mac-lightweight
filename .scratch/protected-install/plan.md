# 受保护首次安装与可牺牲盘验收计划

Status: in-progress
Labels: enhancement, in-progress

## 目标

把正式 App 从用户可写检查件部署到固定 root 所有位置，由 App 触发 helper 注册、管理员批准、
只读 XPC 可达性核验；仅在已授权的可牺牲 `NTFSLAB` 上进行最终挂载、写删、标准整盘推出，
然后由用户在 Windows 复核。Gate 1–5 状态不随此任务改变。

## 实施与检查

1. 固定安装决策及 Apple 一手依据：ADR 0012；明确当前路径、Development 签名、公证及升级边界。
2. RED：helper 健康响应必须绑定精确 challenge；GREEN：加只读 XPC 方法和 App 可用性门禁。
3. RED：安装前拒绝已有目标、符号链接、不可信父目录；GREEN：构建首次安装 pkg，离线核对
   payload、BOM、脚本和签名。不得在构建或离线验证时执行真实安装。
4. 在本机首次安装前重新核对目标路径不存在、macOS 签名身份与包内容；经系统 Installer 安装后
   读取 root 属主、权限、ACL、包清单和签名，启动已安装 App，记录注册／批准／XPC 结果。
5. 实盘前每次重新核对 USB `NTFSLAB` 的整盘 IOMedia 身份、GPT NTFS 数据分区与 EFI sibling，
   保证它仍是用户 2026-09-30 授权的可牺牲 `XMUP22YM`；不在其他盘上试验。用正式 App 发起
   写入，读回和删除固定测试文件，按标准整盘退出；异常结果立即失败关闭。
6. Windows 对照复核须取得 Windows 侧实测结果才能记为通过；没有结果时保持待验证。

## 2026-09-30 本机进展

- 首次 pkg 安装成功；安装后受保护路径、root:wheel、权限、ACL、清单和签名核验通过。
- 已安装 App 的运行环境页未提供注册按钮；v2 服务在 launchd 与系统后台任务中均无记录。
  正在修复 `SMAppService.status == .notFound` 的明确提示和手动注册入口，未知状态继续失败关闭。
- 用户选择稍后批准 helper；本轮不执行注册、系统批准、磁盘挂载、卸载、推出或写删。
- 当前可牺牲盘仍为 `NTFSLAB`，此处仅记录授权范围；使用前必须重新核对物理设备身份与完整拓扑。
- 新源码已为 `.notFound` 增加明确提示和手动注册入口；现机已安装的旧构建不含此修复。
  首次安装包拒绝覆盖，需另行完成安全更新和新旧文件摘要复核后才能让该入口在现机出现。
- 更新预检发现旧 v1 helper 虽未出现在 launchd 活动服务或进程中，但后台任务记录仍为
  `enabled, allowed`。当前没有可证明的跨进程更新互斥或安全注销完成证据，因此不运行
  覆盖/重装脚本。后续先解决旧服务注销与会话静止的可核对协议，再执行受保护更新。

## 交付门槛

- `scripts/check-read-only-boundary.sh`、严格 Release 全量构建与 `scripts/check.sh` 通过。
- pkg 离线核验通过；受保护安装及 XPC 结果单独记录，不用构建成功替代实际运行。
- 快速拔插 BSD 名复用竞态仍按 ADR 0011 保留，不开展用户数据盘试验。
